# E9: Free web checker & launch (P0, ships December 2026)

Goal: first public deliverable, live before 1 Jan 2027, to validate demand and collect emails.

## E9-S1: Check a file on invoqk.com

As a business owner, I want to upload an XRechnung or ZUGFeRD file and get a report, so that I know if it is valid.

- Accepts XML and ZUGFeRD PDF; size limit shown.
- Uses the same API as the plugin (E1).
- Report in German with BT codes and plain-German explanations.

## E9-S2: Understand the report without expertise

As a non-expert, I want errors explained simply, so that I can act on them.

- Same German error texts as the plugin (E3).
- Clear pass or fail headline; "Keine Rechts- oder Steuerberatung" shown.

## E9-S3: Leave my email to get the report or updates

As a visitor, I want to optionally subscribe, so that I get help before the deadline.

- Email capture with explicit GDPR consent; the check works without it.
- Subscribers are tagged by source.

## E9-S4: Keep uploads private

As a visitor, I want my file deleted after checking, so that my data is safe.

- File not stored after the response; stated on the page.
- Rate limit and file validation against abuse.

## E9-S5: Find the site through search

As a German shop owner, I want to find helpful pages, so that I discover Invoqk.

- Pages for "E-Rechnung WooCommerce 2027", "XRechnung Germanized validieren", "ZUGFeRD Fehler BT-10".
- One guide per incumbent plugin (Germanized, German Market, WP Overnight).
- Each page links to the checker and the plugin.

## E9-S6: Publish the WordPress.org listing

As the Invoqk team, we want the free plugin listed in German and English, so that shops can install it.

- Name "Invoqk – E-Rechnung Check & Archiv for WooCommerce", slug invoqk; submit early to reserve it.
- Screenshots of dashboard and error messages; readme meets WordPress.org rules.

## E9-S7: Measure demand

As the Invoqk team, we want demand data, so that the gate decision is based on facts.

- Track checker uploads, email signups and plugin installs.
- Run about 20 merchant interviews; record the go/no-go result.

## E9-S8: Settle brand and legal items

As the Invoqk team, we want legal basics covered before launch.

- Decide on EU trademark for Invoqk.
- Terms and privacy pages, AVV/DPA template, and a no-legal-advice notice.
